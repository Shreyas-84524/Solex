# 🚀 Core Features

## 1. 🧮 Interactive Solar ROI & Installation Cost Calculator

**File:** `cost.html`

The financial calculator allows potential solar customers to quickly estimate whether a rooftop solar installation is financially feasible.

### Capabilities

- **Instant Area-Based Feasibility**
  - Enter the available rooftop area in square metres.
  - Receive estimated solar installation requirements.

- **Estimated Capital Expenditure**
  - Calculates approximate upfront solar installation costs.

- **ROI & Payback Analysis**
  - Estimates the time required for the investment to recover its initial cost.

- **Phased Financial Forecasting**
  - Pre-installation electricity expenditure
  - Estimated installation CapEx
  - Transitional electricity expenses
  - Expected solar savings
  - Long-term reduction in grid electricity dependence

- **Indian Market Support**
  - All financial values are formatted using **INR (₹)**.

## 2. 📊 SoleX Edge — Enterprise & Investor Dashboard

**File:** `indexlogin.html`

**SoleX Edge** acts as the centralized dashboard for monitoring solar projects after a customer begins their clean-energy journey.

### Executive KPIs

Users can monitor:

- 🌱 CO₂ emission reductions
- 💰 Expected financial savings
- ☀️ Solar energy generation
- 📅 Project timelines
- ⚡ Solar asset performance
- 🏗️ Installation progress

### Dashboard Modules

#### 📍 Project Work Tracker

**File:** `slide1.html`

Tracks installation milestones, project phases and deployment progress.

#### ⚡ Expected Energy Savings Analytics

**File:** `slide2.html`

Provides estimated solar yield and potential financial savings based on energy generation and utility costs.

#### 🔋 Solar Asset Information & Inventory

**File:** `slide3.html`

Displays information relating to:

- Solar panel arrays
- Rooftop installations
- Inverter systems
- Asset status
- Installation health

## 3. 🤝 Solar EPC Vendor & Partner Portal

**File:** `vendor.html`

SoleX also creates an ecosystem connecting customers with verified solar EPC contractors.

# 💡 The Problem We Wanted to Solve

Solar energy has enormous potential, but adoption remains unnecessarily complicated.

Customers frequently encounter:

```text
High Upfront Cost
       ↓
Confusing ROI Calculations
       ↓
Multiple Installer Quotations
       ↓
Unclear Vendor Reliability
       ↓
Regulatory Complexity
       ↓
Limited Post-Installation Visibility
```

This creates friction even when solar installation may be economically beneficial.

---

# ☀️ The SoleX Approach

SoleX aims to simplify this process into:

```text
                SOLEX
                  │
        ┌─────────┼─────────┐
        │         │         │
   Feasibility Financing  Vendors
        │         │         │
        └─────────┼─────────┘
                  │
             Installation
                  │
                  ▼
              SoleX Edge
                  │
        ┌─────────┼─────────┐
        │         │         │
     Savings    Assets  Sustainability
```

Our goal is to make solar adoption more **transparent, measurable and accessible**.

# 🎯 Hackathon Vision

SoleX was created by **Team Griffyin Coders** with the aim of simplifying how individuals and organizations understand and approach solar-energy adoption.

The project brings together:

> **Solar Feasibility + Financial Modelling + EPC Vendor Discovery + Project Tracking + Sustainability Analytics**

into one unified platform.

Our hackathon objective was to demonstrate how technology can reduce the complexity surrounding clean-energy investments while improving transparency between solar customers and service providers.
